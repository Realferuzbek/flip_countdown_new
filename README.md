# Flip Countdown
A flip-style Pomodoro timer for students and knowledge workers who want a clean, distraction-free way to manage focus and breaks.

## Demo
Live: https://flipcountdownnew.vercel.app/

## Features
- Pomodoro, short break, and long break modes
- Click-to-edit time input (`MM:SS`) up to 99 minutes
- Background themes (local assets; optional automatic listing via Vercel API)
- Fullscreen mode (browser-supported)
- Multi-language UI (English, Uzbek, Russian)
- End-of-timer alarm with a dedicated stop control and “hard stop” behavior (prevents accidental alarm replay)
- Preferences persisted locally (language, selected background, timer presets)
- Lightweight, framework-free UI (HTML/CSS/JS)

## Tech Stack
**Frontend**
- HTML, CSS
- Vanilla JavaScript (ES modules)

**Tooling**
- Node.js (scripts and local dev)
- `http-server` for static local serving

**Deployment**
- Vercel (static hosting + optional serverless endpoint)

## How It Works
- The app is a static web UI (`index.html`, `styles.css`, `script.js`).
- Timer accuracy uses a deadline-based approach (`Date.now()` and `performance.now()` when available) and updates on a short interval.
- Backgrounds are discovered via `GET /api/backgrounds` on Vercel; if unavailable, the app falls back to `assets/images.json`.
- User preferences are stored in `localStorage` (no accounts, no backend database).
- The alarm is an `HTMLAudioElement`; when the user stops it, the audio is disarmed to prevent replay via media keys until the next timer is set.

## Evidence / Results
- Deployed, publicly accessible demo: https://flipcountdownnew.vercel.app/
- Background discovery implemented in two modes:
  - Vercel serverless listing: `api/backgrounds.js`
  - Static fallback manifest: `assets/images.json` generated by `scripts/gen-images-manifest.mjs`
- Timer designed for stability under tab throttling using a deadline-based remaining-time calculation (see `script.js`).
